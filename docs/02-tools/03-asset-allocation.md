# 资产配置：不要把鸡蛋放在一个篮子里

## 引言

"不要把鸡蛋放在一个篮子里"是投资界的经典格言。这句话的核心就是**资产配置**——通过将资金分散投资到不同的资产类别，降低风险，提高收益稳定性。理解资产配置，是构建投资组合的关键。

## 什么是资产配置？

### 基本概念

**资产配置**（Asset Allocation）是指根据投资目标、风险承受能力和时间期限，将投资资金分配到不同的资产类别（如股票、债券、现金等）的过程。

**简单理解**：不把所有钱投到一种资产，而是分散投资到多种资产。

### 为什么需要资产配置？

#### 1. 降低风险

**原理**：不同资产在不同时期表现不同，分散投资可以降低整体风险。

**例子**：
- **全仓股票**：如果股市大跌，全部亏损
- **股票+债券**：如果股市大跌，债券可能上涨或稳定，降低整体亏损

#### 2. 提高收益稳定性

**原理**：不同资产的风险收益特征不同，组合投资可以平滑收益波动。

**例子**：
- 股票：高收益，高波动
- 债券：中等收益，低波动
- 组合：中等收益，中等波动（更稳定）

#### 3. 适应不同市场环境

**原理**：不同资产在不同市场环境下表现不同，配置可以适应市场变化。

**例子**：
- **牛市**：股票表现好
- **熊市**：债券表现好
- **配置**：无论市场如何，都有表现好的资产

## 主要资产类别

### 1. 现金类资产

**包括**：
- 银行存款
- 货币基金
- 短期国债

**特点**：
- **风险**：极低
- **收益**：低（2%-3%）
- **流动性**：高
- **作用**：应急资金、短期资金存放

**配置比例**：通常10%-20%

### 2. 固定收益类资产

**包括**：
- 债券基金
- 银行理财
- 国债
- 可转债

**特点**：
- **风险**：低-中
- **收益**：中等（3%-6%）
- **流动性**：中等
- **作用**：稳健收益、降低组合波动

**配置比例**：根据风险承受能力，20%-50%

### 3. 权益类资产

**包括**：
- 股票基金
- 指数基金
- 混合基金
- 股票

**特点**：
- **风险**：中-高
- **收益**：较高（长期8%-10%）
- **流动性**：高
- **作用**：长期增值、跑赢通胀

**配置比例**：根据风险承受能力和投资目标，30%-70%

### 4. 另类资产（可选）

**包括**：
- 房地产（REITs）
- 黄金
- 大宗商品

**特点**：
- **风险**：不确定
- **收益**：不确定
- **流动性**：较低
- **作用**：进一步分散风险

**配置比例**：通常不超过10%（可选）

## 经典资产配置策略

### 1. 年龄配置法

**原理**：根据年龄调整风险资产比例。

**公式**：**股票比例 = 100 - 年龄**

**例子**：
- **25岁**：股票75%，债券25%
- **35岁**：股票65%，债券35%
- **45岁**：股票55%，债券45%
- **55岁**：股票45%，债券55%

**优势**：
- 简单易行
- 随着年龄增长，自动降低风险

**劣势**：
- 过于简单，不考虑个人情况
- 可能不适合所有人

### 2. 风险偏好配置法

**根据风险承受能力配置**：

#### 保守型（风险承受能力低）

- **现金类**：20%
- **固定收益**：60%
- **权益类**：20%

**特点**：稳健为主，收益较低

#### 稳健型（风险承受能力中等）

- **现金类**：10%
- **固定收益**：40%
- **权益类**：50%

**特点**：平衡风险和收益

#### 平衡型（风险承受能力中等偏高）

- **现金类**：10%
- **固定收益**：30%
- **权益类**：60%

**特点**：追求较高收益，承担中等风险

#### 进取型（风险承受能力高）

- **现金类**：5%
- **固定收益**：20%
- **权益类**：75%

**特点**：追求高收益，承担高风险

### 3. 目标配置法

**根据投资目标配置**：

#### 短期目标（1年内）

- **现金类**：80%
- **固定收益**：20%
- **权益类**：0%

**原则**：保本为主，流动性优先

#### 中期目标（1-5年）

- **现金类**：20%
- **固定收益**：50%
- **权益类**：30%

**原则**：稳健增长，适当配置权益

#### 长期目标（5年以上）

- **现金类**：10%
- **固定收益**：30%
- **权益类**：60%

**原则**：追求长期增值，可以承担较高风险

### 4. 核心-卫星策略

**原理**：核心资产（稳健）+ 卫星资产（进取）

**配置**：
- **核心资产（70%-80%）**：指数基金、债券基金（稳健）
- **卫星资产（20%-30%）**：行业基金、个股（进取）

**优势**：
- 核心保证稳定
- 卫星追求超额收益
- 平衡稳健和进取

## 如何构建自己的资产配置？

### 步骤1：评估风险承受能力

使用[风险承受能力测试工具](../../tools/risk-assessment.html)评估自己：
- 财务承受能力
- 心理承受能力
- 时间承受能力

### 步骤2：明确投资目标

- **短期目标**：1年内
- **中期目标**：1-5年
- **长期目标**：5年以上

### 步骤3：选择配置策略

根据风险承受能力和投资目标，选择适合的配置策略：
- 年龄配置法
- 风险偏好配置法
- 目标配置法
- 核心-卫星策略

### 步骤4：确定具体比例

根据选择的策略，确定各类资产的具体比例。

**示例**（稳健型，长期目标）：
- 现金类（货币基金）：10%
- 固定收益（债券基金）：40%
- 权益类（指数基金）：50%

### 步骤5：选择具体产品

根据确定的配置比例，选择具体的投资产品：
- 现金类：货币基金（如余额宝）
- 固定收益：债券基金（如纯债基金）
- 权益类：指数基金（如沪深300ETF）

### 步骤6：执行和调整

- **执行**：按照配置比例开始投资
- **定期调整**：每半年或一年回顾一次，根据情况调整
- **再平衡**：当某类资产比例偏离目标时，进行调整

## 资产配置的误区

### 误区1：过度分散

**错误**：买很多只基金，每只都只买一点点。

**正确**：选择3-5只核心基金，集中配置。

### 误区2：不分散

**错误**：全仓一种资产（如全仓股票）。

**正确**：分散到不同资产类别。

### 误区3：频繁调整

**错误**：看到市场变化就频繁调整配置。

**正确**：保持配置稳定，定期（如每年）调整一次。

### 误区4：忽略再平衡

**错误**：配置后就不再管，任由比例偏离。

**正确**：定期再平衡，保持目标比例。

### 误区5：配置与目标不匹配

**错误**：短期目标却配置高风险资产。

**正确**：根据投资目标匹配风险水平。

## 再平衡策略

### 什么是再平衡？

**再平衡**（Rebalancing）是指当资产配置比例偏离目标时，通过买卖调整回目标比例的过程。

### 为什么需要再平衡？

**原因**：
- 不同资产表现不同，比例会自然偏离
- 偏离后风险收益特征会改变
- 需要调整回目标比例

**例子**：
- **初始配置**：股票50%，债券50%
- **一年后**：股票涨到60%，债券降到40%
- **再平衡**：卖出部分股票，买入债券，恢复50:50

### 再平衡方法

#### 1. 时间再平衡

**方法**：定期（如每年）调整一次。

**优势**：简单，不需要判断市场。

**劣势**：可能错过市场机会。

#### 2. 阈值再平衡

**方法**：当某类资产比例偏离目标超过一定幅度（如5%）时调整。

**优势**：更灵活，适应市场变化。

**劣势**：需要监控，可能频繁调整。

#### 3. 混合再平衡

**方法**：结合时间和阈值，定期检查，超过阈值时调整。

**建议**：新手使用时间再平衡，每年调整一次。
