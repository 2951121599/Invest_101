# Invest_101：投资理财从零到一

## 📚 项目简介

**Invest-101** 是一个为投资理财新手打造的完整开源学习体系。本系列内容旨在用最通俗易懂的方式，系统性地介绍投资理财的核心概念、工具和策略，帮助零基础的朋友建立正确的财富观念，避开常见陷阱，迈出稳健投资的第一步。

## 🎯 项目特色

- **零基础友好**：从"钱是什么"开始，逐步深入
- **实战导向**：不仅有理论，更有具体操作指南
- **持续更新**：根据市场变化和用户反馈定期更新内容
- **开源协作**：欢迎所有人参与完善，共同创造更好的投资教育资源

## 📖 内容目录

### 第一阶段：观念筑基

1. 投资、理财与赌博的本质区别
2. 风险收益平衡：你真的了解自己能承受多少风险吗？
3. 时间的魔力：复利计算的惊人效果
4. 通胀：看不见的财富杀手

### 第二阶段：工具认知

1. 从存款到股票：各类投资工具全解析
2. 基金入门：为什么说是指数基金是新手最佳选择？
3. 资产配置：不要把鸡蛋放在一个篮子里
4. 理财陷阱识别：那些年我们交过的"智商税"

### 第三阶段：实战操作

1. 个人财务健康检查清单
2. 建立你的第一个投资组合
3. 基金定投：懒人投资法的科学原理
4. 投资记录与复盘：建立自己的投资系统

### 第四阶段：进阶思维

1. 经济周期与市场情绪
2. 价值投资 vs 趋势投资
3. 行为金融学：我们为何总是做出不理性的投资决策？
4. 终身学习：优秀投资者的成长路径

## 🚀 快速开始

### 如果你是投资新手：

1. 按顺序阅读 `docs/` 目录下的内容
2. 完成每个章节的"思考与实践"部分
3. 使用 `tools/` 中的计算器进行模拟计算
4. 加入讨论，分享你的理解和困惑

### 如果你有投资经验：

1. 直接查看你感兴趣的章节
2. 检查 `advanced/` 目录下的进阶内容
3. 参与内容完善，分享你的实战经验
4. 帮助解答 Issues 中的问题

1. **循序渐进**：不要急于求成，每周掌握1-2个概念即可
2. **动手实践**：用模拟账户或小额资金实际操作
3. **记录思考**：在 `notes/` 目录下记录你的学习心得
4. **参与讨论**：在Issues中提出你的问题，帮助他人解答
