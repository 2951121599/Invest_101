资产配置模板说明
================

这是一个资产配置模板的说明文件。你可以使用Excel创建类似的表格。

模板结构：
---------

1. 资产类别列
   - 现金类资产
   - 固定收益类资产
   - 权益类资产

2. 目标配置列
   - 目标比例（%）
   - 目标金额（元）

3. 当前配置列
   - 当前金额（元）
   - 当前比例（%）

4. 差异列
   - 差异金额（元）
   - 差异比例（%）

5. 调整建议列
   - 需要买入/卖出的金额
   - 调整说明

示例数据：
---------

资产类别          目标比例  目标金额    当前金额    当前比例    差异金额    差异比例    调整建议
现金类（货币基金）   10%     10,000     12,000     12%        +2,000     +2%        卖出2,000元
固定收益（债券）     40%     40,000     38,000     38%        -2,000     -2%        买入2,000元
权益类（指数基金）   50%     50,000     50,000     50%         0         0%         无需调整
总计              100%    100,000    100,000    100%         0         0%         -

计算公式：
---------

1. 当前比例 = 当前金额 / 总资产 × 100%
2. 差异金额 = 当前金额 - 目标金额
3. 差异比例 = 当前比例 - 目标比例
4. 调整金额 = 目标金额 - 当前金额

使用说明：
---------

1. 根据你的风险承受能力和投资目标，设定目标配置比例
2. 记录当前各类资产的金额
3. 计算差异，确定是否需要调整
4. 定期（如每季度）检查一次，进行再平衡

注意事项：
---------

- 不要频繁调整，通常每年调整一次即可
- 调整时考虑交易成本
- 根据市场环境和个人情况灵活调整
- 保持长期视角，不要被短期波动影响
